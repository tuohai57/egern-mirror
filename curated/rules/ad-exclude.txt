# ═══════════════════════════════════════════════════════════════════════════
# 为什么需要它：DNS 层的 ad-full -> reject 是全局的，**不受 rules 顺序影响**。
# 配置里排在广告规则之前的白名单，在 DNS 层救不回来——所以必须在生成广告表时
# 就把这些域名（含子域）剔掉。清单里的每一条都对应配置里一条显式 DIRECT 规则。
#
# ⚠️ 注意 6 个「品牌二级根域」是有意做分层放行的：
#     weibo.com / weibo.cn / qq.com / baidu.com / 163.com / 126.net
#   这几个在 DNS 层整家放行（否则 App 主功能会挂），具体广告端点交给模块层拦：
#     · 微博广告 → loonlab-plugin-ae197c04（模块里 REJECT 具体 ad 子域）
#     · 腾讯/QQ 广告 → 配置里手写的 gdt.qq.com / otheve.beacon.qq.com 等精准 REJECT
#     · 百度广告 → fmz200 各模块 + 手写 mobads.baidu.com 等
#     · 网易广告 → fmz200/kelee 各模块
#   所以「这几个品牌在 DNS 层拦不住」是设计，不是漏。改之前先想清楚。
